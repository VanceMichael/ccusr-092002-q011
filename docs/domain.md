# 领域资料

区域公共品牌标志授权与生产主体、产品规格和检测材料关联，展会展品信息不代表全系列产品获准使用标志。

`contracts/entities.json` 保存外部数据的首批交换字段。来源编号（`*_ref`）仅表示提交方对同一记录的识别符，不假定全局唯一以外的语义；示例文件不包含真实个人资料。运行时持久化文件由 `DATABASE_PATH` 决定；时间字段使用带时区偏移的 ISO 8601 字符串。

## 标签码领用与核销

印厂按企业获准的规格预制带验证编号的板材标签，每个编号的去向按五个环节登记，全程写入只追加的事件台账（`label_events`）：

1. **印制批次**（print batch）：印厂预制编号，编号预印产品规格；
2. **交付箱件**（box）：标签密封装箱、整箱交付到生产企业，保管人随之转移；
3. **企业领用**（issue）：企业凭有效授权凭证领用，凭证企业与规格必须与标签一致；
4. **实际贴附**（applied）：离线设备回传编号与产品批次，`(device_id, device_event_id)` 构成重传幂等键；
5. **异常核销**：遗失挂失、寻回、作废（含回收核销）、授权到期冻结。

### 关键规则

- **授权凭证是不可修改的外部依据**：`authorizations` 仅允许新增（同内容重复收录幂等），数据库触发器禁止 `UPDATE`/`DELETE`，服务层拒绝以不同内容覆盖同一凭证编号。
- **一个码只能贴到一个产品批次**：离线设备整包重传时，同一事件键原样重放返回幂等结果、不产生第二条台账；同键换内容、或换事件键把已贴附编号改贴其他批次，一律 `409`。
- **授权到期不溯及既往**：到期前已经贴附售出的板材验真仍然通过（凭证状态标注 `expired` 并给出口径说明）；尚未贴附的剩余标签——无论已领用还是仅交付——由到期冻结任务置为 `frozen`，停止领用与贴附。
- **遗失可识别、可追责**：挂失是叠加标记而非删除，公众扫码仍展示企业与规格，但同时显著显示 `lost` 异常；挂失事件快照当时保管人，品牌方可按印制批次查出全部遗失编号的最后保管人。
- **已贴附售出编号受保护**：不能挂失、不能作废，避免把合规在售商品打成假货。

### 公众验真异常码（`anomaly_code`）

| 码 | 含义 |
| --- | --- |
| （无，`valid=true`） | 已贴附且无异常 |
| `not_applied` | 编号真实但尚未贴附到任何产品批次，疑似提前流出或挪用 |
| `lost` | 标签已挂失，可能被挪用 |
| `frozen` | 授权到期，未使用标签已停用 |
| `voided` | 标签已作废 |
